# palimpsest

> 한 프로젝트의 라이프사이클 전체 — 의사결정과 그것이 코드에 반영된 모습, 코드 뒤에 비치는 기획·설계·구현 당시의 의도와 관계성 — 을 투명하게 드러내는 **장기기억·지식 큐레이터**.

코드베이스는 palimpsest다: 표면의 코드 아래에 무수한 의사결정의 층이 비쳐 있으나 잘 드러나지 않는다. 이 시스템은 그 아래 층을 다시 읽을 수 있게 만든다.

## 목표

- LLM·에이전트 **할루시네이션 최소화** (근거 있는 grounding)
- **context rot 없는 점진적 컨텍스트 획득** (필요한 시점에 필요한 부분만)
- **의사결정·의도 투명화** (코드 뒤의 의도를 모두가 볼 수 있게)

## 핵심 기능

**Preserve**(git=SoT 보존·신선도) · **Relate**(관계 그래프 투영) · **Recall**(점진 회상) · **Curate**(근거 결박 합성) · **Reconcile**(브랜치 간 컨텍스트 중재)

## 스택

- **Python** (GraphRAG·RAG·그래프·LLM 생태계 지배력)
- **Neo4j** 1차 (그래프 + 네이티브 벡터 = GraphRAG 단일 DB; 택일은 첫 스파이크에서 확정)
- ditto에는 **MCP 서버**로 노출 (seam 대체)

## 상태

**seed / 정초.** 정체성·목적·기능·잠긴 결정은 [`docs/VISION.md`](docs/VISION.md) 참조. MVP·스키마·캡처/회상 메커니즘·DB 택일·통합 형태는 자체 deep-interview로 결정한다.

## 관계

짝이 되는 자율 엔지니어링 도구 **ditto**의 메모리 seam을 장기적으로 대체한다. ditto는 palimpsest의 소비자다. 근거: ditto `ADR-0021`.
